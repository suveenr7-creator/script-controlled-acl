# Phase 1: Create the Test User and Roles

## Steps
1. Log in to the ServiceNow instance with **admin** access.
2. Navigate to **User Administration > Users** and click **New**.
3. Create the test user with these details:
   - User ID: `EEE User`
   - First name: `EEE`
   - Last name: `User`
   - Email: `eeeuser@gmail.com`
4. Save the user record.
5. Navigate to **User Administration > Roles** and click **New**.
6. Create the custom roles `bb1`, `bb2`, `bb3`, and `bb4`. Add a short description for each role.
7. Assign all four roles to the **EEE User** account.

## Video narration
"First, I create a test user called EEE User. Then I create four custom roles—bb1, bb2, bb3 and bb4—and assign them to this user. These roles will control which ACL operations the user can perform."

## Result
The EEE User account exists and has the four custom roles assigned.
